# Reuse the masters across lessons

Do not commission an image per post. Keep the same master for a recurring theme; change the lesson, editable text and crop only when it remains readable.

| Set | Reuse examples | Keep accurate |
|---|---|---|
| Learning moments | Study habits, revision routines, practice reminders, reflection, peer support | Do not present fictional learners as real testimonials, staff or app users |
| Concepts | Start/end illustration, method card, worked example, practice question | Use the matching editable diagram and verify any changed numbers |
| Assam environments | Geography introductions, ecology topics, regional knowledge, information headers | Identify as regional concepts; source exact place/current condition claims separately |
| Livelihoods | Everyday vocabulary, local economics, contextual examples, community information | No claim of specific community, family, enterprise or technical equipment design |
| History | Architecture vocabulary, source comparison, evidence vs conjecture, heritage introductions | Include reconstruction caption and source brief; get heritage/editorial review for named-site factual use |
| Campaign backgrounds | Learning launch, information update, opportunities, contribution invitation | Add supplied logo and bilingual text as editable overlays; no invented dates/services/results |

## Square-card production

1. Select by ID in gallery.html and retain its classification/caption in the post record.
2. Use the original master PNG in a 1080 × 1080 editable brand template. Preserve its composition; avoid clipping hands, equipment or meaningful river features.
3. Add one headline and one idea. Open upper-left space is composition guidance, not an automatic readability guarantee. Add a solid ivory panel when the selected crop is busy.
4. Use the existing licensed Assamese/English fonts and token palette. Independently review Assamese text after shaping and wrapping. No text is baked into these masters.
5. For CI-01 through CI-08, use the matching SVG explanation for the actual method. All labels, numbers and typography remain editable.
6. Add supplied brand elements separately using the existing brand kit. Keep owner-supplied source artwork's rights record attached to the resulting composite.
7. Keep the manifest alt text and adapt it when the crop or lesson changes. Export the completed card, not an unlabeled documentary-looking scene.

## Vertical reuse

Use a square master within an ivory 9:16 frame rather than stretching it. Place bilingual copy above/below the square and retain the classification in the post/caption. Campaign backgrounds have extra empty area for this use; historical diagrams should remain fully visible.

## What's deliberately outside this pack

Real proprietor/team photography, live app screenshots, exact current maps, event reporting and historical costumes require genuine supplied media or separate evidence briefs. This collection supplies reusable illustration masters, not proof that the wider Assam information services have launched.
